Ranking Logic — strict order

  1. Valid completion — elapsed time from start to finish ≥ 9h 26m runtime
  2. Highest Total Tokens Earned
  3. Shortest Completion Duration (fastest genuine finish)
  4. Earliest Completion Date (final tiebreaker)

How the leaderboard is validated

Completion Date The date the 7th course was completed (the “Completed At” timestamp) — a calendar date, not a duration.
Completion Duration Elapsed time from first start to final completion, shown as e.g. 1D 3H 56M. Among equal tokens, the shortest valid duration ranks higher.
Validity gate The 7 courses hold ~9h 26m of content, so a path “finished” in less elapsed time than the runtime cannot be genuine — those completions are flagged (⚠) and set aside from the ranking, pending HC review.
